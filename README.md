# GestorGastos

App Android para gestionar gastos compartidos entre amigos, familia o trabajo.

## Funcionalidades

- Login y Registro de usuarios
- Categorias: Companeros, Trabajo, Familia
- Registrar gastos indicando quien pago y cuanto
- Ver resumen de deudas

## Tecnologias

- Kotlin
- Jetpack Compose
- MVVM + Clean Architecture
- Retrofit para API REST

## Requisitos

- Android Studio
- API REST corriendo en http://54.197.208.12:8000/docs#/
